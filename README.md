# Happy Birthday Lilly! 🎂✨

A heartfelt interactive birthday story & tribute web application built for Lilly (Muu) for 2026.

## ✨ Features
- 📖 **Interactive 3D Story Book**: Tap to open a 3D letter with smooth typewriter text animation.
- 📸 **Captured Moments (Polaroid Gallery)**: Authentic polaroid frames displaying real memories with a click-to-zoom Lightbox modal.
- 🫂 **A Promise**: A touching message and promise typewriter screen.
- 🌹 **Words From My Soul**: Beautifully styled Tamil romantic poetry.
- 💍 **The Question**: Playful proposal with a runaway "No" button (supports desktop hover & mobile touch) and a pulsing "YES!" button.
- 🎥 **Embedded Video Player**: Watch John's personal video message directly inside the web experience.
- 🎂 **Virtual Birthday Cake**: Tap the candle to blow it out and make a wish, triggering fireworks and confetti.
- 🎵 **Web Audio Synthesizer**: Built-in dreamy romantic melody with audio toggle and interactive chimes (zero external audio loading issues).
- 🎈 **Realistic Floating Balloons & Stars**: Dynamic canvas particle effects with realistic balloon strings and gentle bokeh.

## 🚀 GitHub Pages Deployment
To view this live on GitHub Pages:
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`.
3. Click **Save**.
4. Your website will be live at `https://theworldofkabi.github.io/Birthday-/` (or your GitHub Pages username domain).
